# 🌦 Weather & Outfit Bot

Telegram-бот, который показывает погоду и рекомендует, что надеть.

## Возможности

- 🌤 Погода сейчас
- 📅 Прогноз на 7 дней
- 🏙 Выбор города
- 🇷🇺 Город + регион + страна
- 🌡 Температура
- 🤔 Ощущаемая температура
- 🌧 Вероятность осадков
- 💧 Количество осадков
- 💨 Ветер
- 💧 Влажность
- 👕 Рекомендация по одежде
- 📍 Получение погоды по геолокации
- 🔒 Обязательная подписка на Telegram-канал

## Технологии

- Python
- aiogram 3
- aiohttp
- Open-Meteo
- Railway
- GitHub

## Переменные Railway

В Railway → Variables добавь:

TG_BOT_TOKEN=ТОКЕН_БОТА

REQUIRED_CHANNEL=@username_канала

Например:

TG_BOT_TOKEN=123456:ABCDEF...

REQUIRED_CHANNEL=@my_weather_channel

## Telegram-канал

Бота необходимо добавить администратором в канал.

Это необходимо для проверки подписки пользователей.

## GitHub

Загрузи в репозиторий:

bot.py
requirements.txt
Procfile
railway.toml
.gitignore
README.md

Не загружай токен Telegram в GitHub.

## Railway

1. Создай новый проект Railway.
2. Выбери Deploy from GitHub Repo.
3. Выбери этот репозиторий.
4. Открой Variables.
5. Добавь TG_BOT_TOKEN.
6. Добавь REQUIRED_CHANNEL.
7. Сделай Deploy.

## Использование

Пользователь запускает:

/start

Если он не подписан:

📢 Подписаться на канал
↓
✅ Проверить подписку

После подтверждения появляется меню:

🌤 Погода сейчас
📅 7 дней
🏙 Выбрать город
📍 Моя геолокация

## Без базы данных

В текущей версии SQLite не используется.

Город пользователя хранится только в памяти текущего запуска бота.
